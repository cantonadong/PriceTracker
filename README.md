# 价格守望（Chrome 扩展）

无需构建工具的 Manifest V3 价格监听扩展。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 建议将“价格守望”固定到浏览器工具栏。

## 使用

打开商品页并点击扩展图标，在菜单中选择“添加价格监听”。移动鼠标定位价格元素并点击，在确认界面核对识别价格、填写目标价格后保存；确认前可点击“重新选择元素”。通过插件菜单中的“查看监听列表”进入管理页面。

扩展每小时请求商品地址并根据保存的 CSS 选择器读取价格。商品页改版后，可在监听列表中点击“◎”重新选择元素。

## 浏览器同步

同步版自动通过 `chrome.storage.sync` 同步监控商品、链接、价格选择区域、目标价格、通知开关、自定义标题和列表顺序。删除也会同步；离线设备重新连接不会恢复已删除的同一条监控。删除后重新添加属于新的监控。

当前价格、更新时间、币种、抓价错误和到价通知状态留在各设备本机。另一台电脑首次收到列表时，价格显示“—”，点击“全部刷新”取得本机价格后再判断是否已达目标。价格刷新不会重置标题或手工顺序。

各电脑需要在同一种浏览器中登录相同同步账号，开启扩展数据同步，并手动安装相同的固定 ID 同步版。Chrome 与 Edge 的同步服务各自独立。解压扩展不保证自动安装到另一电脑。

设置页底部显示写入状态，以及“导出列表”和“导入列表”。“已写入浏览器同步存储”表示浏览器接受了数据，不能表示云端上传或另一设备接收已经完成；浏览器离线或关闭账号同步时也可能显示此状态。扩展无法可靠读取账号同步开关。

Chrome 同步空间约 100 KB，单项 8 KB，最多 512 个键；标题、网址和选择区域的长度会影响可容纳的监控数量。超出配额或写入失败时，数据保留在本机，页面显示原因并安排重试。删除标记也占空间，不自动清理。

### 现有解压版迁移：先导出，再切换 ID

原 1.1 解压版没有固定 `key`，扩展 ID 可能随安装目录变化，浏览器的数据按 ID 隔离。固定 ID 同步版不能直接读取旧 ID 的本机列表。

1. 在原安装目录更新本仓库当前代码，或将 `PriceTracker-1.1-migration.zip` 解压并覆盖原安装目录。准备版没有 `key`，保留原扩展 ID。
2. 在 `chrome://extensions/` 重新加载旧扩展，重新打开列表，点击“导出列表”，保存 JSON 备份。
3. 将 `PriceTracker-1.1-sync.zip` 解压到另一个固定目录，使用“加载已解压的扩展程序”安装。同步包的 manifest 包含固定公钥，不要移除或更换它。
4. 在新扩展列表页点击“导入列表”，选择刚保存的 JSON。核对商品、标题、目标价和顺序；确认后停用旧 ID 扩展，避免两份扩展重复刷新或通知。
5. 在其他电脑安装同一份 `sync.zip`，检查扩展 ID 一致，等待浏览器同步。无需再次导入同一备份。

本仓库工作目录的 manifest 暂时保留无 `key`，让已安装用户可以先导出。**跨电脑使用请安装固定 ID 的 sync.zip，不能仅把当前源目录分别解压加载。**以后更新固定 ID 版时始终使用包含同一公钥的同步包，并覆盖其原安装目录。

导入会合并备份商品，不自动删掉其他已有商品；不同 ID 的相同商品链接可能同时保留。已经同步删除的同 ID 商品不会通过导入恢复。备份含监控网址和配置，保存在你选择的本地文件中。

### 打包

在项目根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package-sync.ps1
```

脚本输出 `PriceTracker-1.1-migration.zip`、`PriceTracker-1.1-sync.zip` 和固定扩展 ID。公钥保存在 `extension-public-key.txt`，私钥不写入仓库。打包仅复制运行文件和图标，不包含 `.git`、计划或工具。

### 多电脑验收（由用户执行）

- 导出旧列表后迁移，核对标题、目标价和顺序。
- 第二台电脑收到列表，刷新前价格为“—”，不误报已达目标。
- 分别修改标题、目标价和顺序，确认两边最终一致；不同设备修改不同字段能够合并。
- 离线编辑后重新连接；另一台设备删除的监控不会复活，重新添加可正常同步。
- 刷新本机价格，确认不会覆盖标题、排序或另一设备价格。
- 观察同步失败提示；本机监控仍可使用。

本次按用户要求未运行测试，实际跨设备同步效果需按以上步骤确认。

## 限制

- 需要登录、验证码或反爬验证的页面可能无法后台读取。
- 完全由 JavaScript 异步渲染且初始 HTML 不含价格的网站可能无法后台读取。
- 不同地区、登录状态或 Cookie 导致的价格差异，以后台公开请求取得的结果为准。
