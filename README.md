# 价格守望（Chrome 扩展）

无需构建工具的 Manifest V3 价格监听扩展。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录。
4. 建议将“价格守望”固定到浏览器工具栏。

## 使用

打开商品页并点击扩展图标，在菜单中选择“添加价格监听”。移动鼠标定位价格元素并点击，在确认界面核对识别价格、填写目标价格后保存；确认前可点击“重新选择元素”。通过插件菜单中的“查看监听列表”进入管理页面。

扩展每小时请求商品地址并根据保存的 CSS 选择器读取价格。商品页改版后，可在监听列表中点击“◎”重新选择元素。

## 限制

- 需要登录、验证码或反爬验证的页面可能无法后台读取。
- 完全由 JavaScript 异步渲染且初始 HTML 不含价格的网站可能无法后台读取。
- 不同地区、登录状态或 Cookie 导致的价格差异，以后台公开请求取得的结果为准。
