# 价格守望（Chrome 扩展）

无需构建工具的 Manifest V3 价格监听扩展。

## 安装和更新

1. 打开 `chrome://extensions/`，开启“开发者模式”。
2. 选择“加载已解压的扩展程序”，加载扩展目录。
3. 已安装用户在原目录更新文件，重新加载扩展即可；已有列表自动接入后台同步，不需要导入导出。

## 使用

打开商品页并点击扩展图标，选择“添加价格监听”。定位价格元素并点击，确认识别价格、填写目标价格后保存。

列表支持按当前价格、目标价格依次升序自动排序，以及手工拖动排序。标题修改在原位输入，Enter 保存、Esc 取消；自定义标题和手工顺序不会被价格刷新覆盖。价格区域调整按钮可重新选择商品页价格元素。

## 自动后台同步

使用同一浏览器同步服务，登录相同账号并开启扩展数据同步，在其他电脑安装本扩展后，监控列表自动同步。没有同步开关、同步按钮或导入导出步骤；已有本机列表也自动加入同步。

同步内容包含监控商品、链接、价格选择区域、目标价格、通知开关、自定义标题和排序。删除操作也会同步，离线设备重连不会恢复已删除的同一条监控。删除后重新添加属于新监控。

当前价格、币种、刷新时间、抓价错误和到价通知状态由各设备分别维护。新收到的商品在价格未知时显示“—”，后台自动尝试抓取价格，此后每小时更新；不会把未知价格当成零元。手动刷新仍然可用。

正常同步在后台进行，不显示操作区域。只有浏览器同步存储写入失败时提示原因；列表保留在本机并自动重试。浏览器在离线或关闭账号同步时也可能接受本地同步存储写入，扩展无法据此确认云端或其他电脑已经收到。

Chrome 同步空间约 100 KB，单项约 8 KB，最多 512 个键。标题、链接、价格选择区域和删除标记会占用空间。超出配额时不丢弃数据，继续保留本机列表并提示原因。Chrome、Edge 等不同同步服务之间不保证互通；解压扩展不保证自动安装到另一电脑。

### 扩展身份（维护说明）

固定 ID 为 `ljbffjpoegfcdkmacohmgagkbijmhoel`，与当前用户原来从 `D:\Dev\PriceTracker` 加载的扩展一致，已对照浏览器安装配置核实。新旧 ID 不变，所以本地 storage 不需要搬迁。

`manifest.key` 使用现有 Windows 安装路径的 UTF-16LE 字节作为固定身份材料。Chromium 无 key 时对规范化路径字节计算 SHA-256；有 key 时对 Base64 解码字节执行同一 ID 计算。采用相同字节保留旧 ID，并使其他电脑的安装目录不再影响 ID。这是解压版的身份兼容方式，不是用于 CRX 签名的 RSA 公钥；不要换回之前随机生成的公钥或按其他电脑目录重新生成 key。

参考：[Chromium ID 生成代码](https://github.com/chromium/chromium/blob/main/components/crx_file/id_util.cc)、[manifest key 解析代码](https://github.com/chromium/chromium/blob/main/extensions/common/extension.cc)。

## 打包

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package-sync.ps1
```

脚本只生成一个 `PriceTracker-1.2-sync.zip`，原样保留 manifest 中的固定身份，并检查 ID。包内只包含运行文件、图标和 README。

## 用户验收

- 在原目录更新并重新加载扩展，原列表、标题、目标价和顺序保留。
- 另一电脑安装同一份包，浏览器账号同步已开启时自动收到列表。
- 修改标题、目标价和顺序，另一设备最终一致；离线编辑恢复联网后合并。
- 删除监控不会复活；本机价格刷新不覆盖标题、排序或其他设备价格。

按用户要求未运行测试；实际跨设备同步效果需由用户确认。

## 价格读取限制

- 需要登录、验证码或反爬验证的页面可能无法后台读取。
- 网站结构变化时可重新选择价格区域。
- 不同地区、登录状态或 Cookie 导致的价格差异，以该设备实际取得的价格为准。
